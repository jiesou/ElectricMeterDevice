# 下位机 Agent 文档

本目录只维护当前 PlatformIO 下位机仓库的 Notes。上位机代码和系统级资料的位置见根目录 [AGENTS.md](../../AGENTS.md)。

- `decisions/*`：本下位机已由用户确认的设计决策，包括驱动边界、硬件接口、协议实现约束和测试约定。
- `research/*`：针对下位机的调研、实验记录和方案比较；内容供后续决策参考，不构成实现要求。

## 规矩

- 引用任何文档前先确认它属于哪个仓库、哪个目录，以及是否仍有效。
- 上位机的决策不会自动成为下位机决策。仅当涉及共享协议/API 时，引用主项目的具体源码或文档，并写清对固件的约束；不要整篇复制。
- Agent 自己的研究和未确认方案写入 `research/`，不得放进 `decisions/`。
- 只有用户明确确认的下位机方案，才写入 `decisions/`。
