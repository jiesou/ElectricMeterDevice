## 2. 文档编码体系与最大坑：同号不同内容

编码前缀 = 出版主体：

- `ZTY0.464.xxx` —— 浙江正泰**仪器仪表**有限责任公司（老体系）
- `ZTW0.464.xxx` —— 浙江正泰**物联技术**有限公司（新体系，2023 批量）

**最大的坑：同一个文档编码，官网挂的和微信小程序给的可以是两份完全不同的文件。**

| 编码 | 官网版 | 小程序版 |
| --- | --- | --- |
| `ZTW0.464.0090` | 12 页，无寄存器表 | 16 页 DDSU666.011，含寄存器表 |
| `ZTW0.464.0105` | 17 页，无寄存器表 | 25 页 DTSU666.014，含寄存器表 |

已用 md5 验证过：官网版与小程序某版本曾字节完全一致，确认是两份独立文件。

**实践结论：认编码 + 页数 + 内容，不能只认编码；官网链接不可作为寄存器表的依据。**

`ZTW0.464.0083` 全网零命中（官网枚举、Wayback 快照、精确搜索均无），大概率是 0090 的误记或旧临时号，不必再追。

## 3. 型号命名规则

说明书 1.3 节「产品型号的组成及代表意义」给出：

```
D | D / TS / SS | Y / U | 666 | 设计序号
```

| 位置 | 含义 |
| --- | --- |
| `D` | 电子式电能表（所有型号固定头） |
| `D` / `TS` / `SS` | 接线方式：单相 / 三相四线 / 三相三线 |
| `Y` / `U` | 安装方式：预付费 / 导轨式 |
| `666` | 系列代号，固定不变 |
| 末位 `.011` `.014` | 设计序号（批次流水号，**说明书不解释差异**） |

展开：

| 型号 | 读作 | 说明 |
| --- | --- | --- |
| **D**D**SU**666 | 电子式·单相·导轨式 | 手上的单相表 `DDSU666.101.0002` |
| **D**T**S**U666 | 电子式·三相四线·导轨式 | |
| **D**S**S**U666 | 电子式·三相三线·导轨式 | |
| DDS**Y**U666 | 预付费版（DDSYU666-B） | 手机充值 + 拉合闸 |

**变体号演进**：`DDSU666.004`（2020 英文出口版）→ `DDSU666.010/011`（2023 单相）→ `DTSU666.014`（2023 三相）。同变体号共用同一份说明书，`.010` 与 `.011` 无独立文档。

**接线方式对寄存器的影响**：单相 `2000H` 直接是 U/I；三相 `2000H` 是 **Uab**（A、B 相间电压）。混用型号会读错。

## 4. 直采式 vs 互感式：原理与量化差异

### 4.1 选型表（表1，均为 220V / 2 模）

| 型号 | 电流规格 | 脉冲常数 | 准确度等级 |
| --- | --- | --- | --- |
| DDSU666（单相） | 0.4-1(100)A / 10(100)A | **800** | 有功1级 / B级 |
| DDSU666（单相） | 0.25-0.5(80)A / 5(80)A | **800** | 有功1级 / B级 |
| **DDSU666（单相）** | **0.015-0.075(6)A / 1.5(6)A** | **6400** | **有功0.5S级 / C级** |
| DTSU666 / DSSU666（三相） | 直采 0.25-0.5(80)A / 10(100)A | 800 | 1级 / B级 |
| DTSU666 / DSSU666（三相） | 互感 1.5(6)A | **6400** | 0.5S级 / C级 |

**型号名一模一样，不换名字**，只能靠电流规格 + 准确度等级辨认。互感式的标志是 `1.5(6)A` 电流规格且等级跳到 0.5S/C 级。

> ⚠️ 单相互感式（1.5(6)A / 6400）**确实存在**，只是当时没买。候选链接：<https://detail.tmall.com/item.htm?id=576124850312&skuId=6057673195357>（未登录无法读取详情，待确认具体 SKU 规格）。

### 4.2 原理

**直接接入式（分流电阻）**：主回路全额电流流过表内毫欧级分流电阻，采样其两端压差 $U = I \cdot R_s$。
80A 满量程对应压差仅几十毫伏 → 分流电阻必须极小（否则自身功耗过大）→ **小电流时信号淹没在 ADC 噪声里**。
主回路必须断开接线把表串进去；粗铜排发热；表在主回路内，不隔离。

**互感式（电流互感器 CT）**：主回路导线穿过高磁导率磁芯，靠磁感应耦合到二次绕组，二次输出毫安级电流，再经取样电阻转电压送 ADC。
绝缘隔离，主回路可不断开（开口 CT 直接卡线）；换量程只需换 CT 而不必换表。
⚠️ **CT 二次侧绝不能开路**（铁芯不饱和会产生数千伏高压），必须先接好 9/10 端子再通主回路电。

### 4.3 为什么灵敏度差 13 倍

起动电流（表3，功率因数 1.0）：

| 接入方式 | 等级 | 起动电流 | @220V 等效功率 |
| --- | --- | --- | --- |
| 直接接入 | 1级/B级 | $0.04 I_{tr}$ = **0.02 A** | **≈ 4.4 W** |
| 直接接入 | 2级/A级 | $0.05 I_{tr}$ = 0.025 A | ≈ 5.5 W |
| **互感器接入** | 1级/B级 | $0.04 I_{tr}$ = **0.003 A** | **≈ 0.66 W** |
| **互感器接入** | **0.5S级/C级** | $0.02 I_{tr}$ = **0.0015 A** | **≈ 0.33 W** |

其中直采 $I_{tr} = 0.5\text{A}$，互感 $I_{tr} = 0.075\text{A}$（表1 备注1 定义 $I_{min}$、$I_{tr}$、$I_{max}$）。

**本质是同一颗 ADC 用在差 50 倍的满量程上**：直采满量程 80A，起动占 1/4000；互感满量程 1.5A，占 1/1000。占比越小信噪比越高，与标称精度等级无关。

**潜动**（表3 后半 / 3.2.2）：电压加至 115% $U_n$、电流回路开路时，输出脉冲不得超过 1 个。空载不走字，对"电器通断检测"有利。

### 空载能不能工作

**可以，但必须接 L + N。**

- 电源取自电压回路（关键零部件：电源变压器 `DB24K-220C`），只接零线表不工作
- 电流回路（端子 3/4）悬空不影响：LCD 正常显示、RS485 正常通信
- LCD 为**温宽型无背光**（说明书全文无"背光"字样），被动反射式，通电即显示，**不存在"带负载才亮"**
- 说明书表10 把"没按接线图接线，特别注意电压的 N 所在位置"列为显示故障原因，说明空载显示是厂家预期工况

最小可用接线（调试/标定）：

```
L ──→ 端子 1
N ──→ 端子 2
4   ──→ 悬空（或接负载）
24/25 ──→ 单片机 RS485
```

## 6. 脉冲输出 vs RS485

**两者是独立物理端子**，不走同一路。说明书 7.3.1 功能端子图给出 RS485 / 脉冲输出 / 开关量输出三张独立接线图。RS485 接口只有**一个**。

脉冲输出规格（5.3 输出功能）：**无源光电隔离型**，输出 **80 ± 16 ms 方波**。

⚠️ 光耦开漏输出**不能直接接 MCU GPIO**，必须外接上拉 + 光耦/三极管隔离（如 6N137、PC817、2N2222），或驱动 24V 继电器/计数器线圈。**绝不可把 24V 脉冲直接灌进 ESP32 IO。**

80 ms 脉宽对 ESP32 边沿计数非常友好，无需额外去抖。

**但脉冲不适合小负载实时检测**：4.4 W 负载下 800 imp/kWh 需约 1023 秒才一个脉冲。要检测"点一盏灯"，应轮询 `2004H` 瞬时功率。

## 7. 与几块钱电流模块的关系

**传感器本体确实都便宜，但表贵在计量链，不在传感器。**

| | 第三方模块 | 计量级电能表 |
| --- | --- | --- |
| 传感器 | 霍尔片（几毫米硅片） | 霍尔片 + 高磁导率磁芯 |
| 磁路 | 空气，漏磁严重 | 磁通收集器，把磁通全引导给霍尔 |
| 基准 | 片内基准，温漂几十 ppm/℃ | 低温漂基准 + 精密分压电阻网络 |
| ADC | 普通 ADC | 专用 Σ-Δ ADC（24 位有效） |
| 校准 | 出厂一次性粗调 | 全量程多点校准 + 温度补偿曲线 |
| 铁磁材料 | 不控制 | 专门选材抑制磁滞（小电流误差主因） |

两类常见第三方模块：

- **电流互感器模块**（ZMCT103C 等，1~3 元）—— 与表互感式同原理。输出电流需外配约 100Ω 采样电阻转电压。**只测交流**，二次侧不可开路。
- **霍尔电流传感器**（ACS712 / ACS723 / CH 系列，3~8 元）—— 交直流均可，输出电压直进 ADC，无需采样电阻。ACS712-5A 灵敏度 185 mV/A，但 offset 典型 ±50~150 mV，需软件做零点自校准。
- ⚠️ 标"几十上百安"的大绿板是电烙铁/电钻用的，量程过大，测小负载等于用 100A 枪打蚊子。

**市电侧必须隔离。** ESP32 不得直接接触 220V；霍尔和 CT 的价值正在于此（磁耦合 / 变压器耦合，不导通）。不要为了省钱用采样电阻直连方案。

## 8. 关键认知：能不能测到小负载，取决于量程匹配，不取决于表贵不贵

**贵的表在小电流下不一定更准。**

三相互感式额定 1.5(6)A，但若电流变比配成 100（即 CT 100/5A），量程就是 100A。测一盏 9W LED（0.04A）时：

$$0.04\text{A} / 100\text{A} = 0.04\% \text{量程}$$

相当于用 100A 量程的体重秤称一粒米，读数大概率就是 0.00。**这不是表不好，是量程配错了。** 计量级芯片同样读不出来，因为 ADC 满量程被占满。

### 量程配置建议

| 想测的负载 | 建议 CT | 表内电流变比 |
| --- | --- | --- |
| 一盏 LED 0.04 A | 5/1A 或 1.5A 级 | 5 或 1.5 |
| 电暖器 5 A | 10/5A | 10 |
| 全屋总回路 30 A | 75/5A | 75 |

变比设置范围 **1～9999**（说明书 5.2）：Modbus-RTU 协议下可设小数，DL/T 645-2007 下只能设整数；电压变比和电流变比乘积不得大于 1000000。
未设变比时读出的是 CT 二次侧量程值。

## 9. 小负载检测的三个量行为不同

| 寄存器 | 量 | 对小负载的表现 |
| --- | --- | --- |
| `2000H` | 电压 U | 与负载无关，永远可读 |
| `2004H` | 瞬时有功功率 P | **由采样波形算出，一盏灯照样有读数** —— 首选 |
| `2002H` | 电流 I | 低于 $I_{min}$ 无精度指标 |
| `4000H` | 累计电能 | 须过起动电流才累加，小电流段精度无保证 |

阈值建议：**10 W 以上判为开，20 W 以上判为大功率电器**。落在起动电流之上，判稳。
